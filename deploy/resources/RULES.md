# Правила отрисовки

## 1. Порядок индикации

Геометрия — 1080×1920 (портрет), ветка `dev-pi2w`. Координаты слотов — `deploy/configs/renderer.toml`.

1. Задний фон - omxplayer видеопоток (output.mp4, 1080×1920) - **layer0** (Z=1)
2. Фоновая картинка (1080×1920px) - BACK.png - **layer1** (Z=2)
3. Иконка режима (1080×1920px) - calling.png, firealarm.png.. - **layer2** (Z=3)
4. Иконки грузоподъемности (237×59px) - weights/load_n.png - **layer3** (Z=4)
5. Номер этажа — шрифт CalSans260 (font renderer, слот 450×239px; PNG `chars/` больше не используются) и стрелки (arrows/up.png, down.png, 172×191px) - **layer3** (Z=4)
6. Уведомления (1080×270px) - notifications/notif_*.png - Z=5

- BACK.png - полупрозрачная картинка на весь экран, накладывается на видео
- Картинки режима (в случае если `mode != 0`) накладывается на BACK.png
- Иконка грузоподъемности накладывается либо на BACK.img либо на картинку режима и присутствует в любом режиме работы, если `load_idx != 0`
- Иконки символов и стрелок накладываются либо на BACK.img либо на картинку режима

## 2. Логика индикации

- При возникновении любого из режимов: `MODE_FIRE_ALARM`,`MODE_MALFUNCTION`,`MODE_LOADING` ,`MODE_OVERLOAD,` `MODE_SEIS_ALARM`,`MODE_FIREMANS`,`MODE_SERVICE`,`MODE_EVACUATION`,`MODE_UPS_MALFUNCTION`,`MODE_DISPATCH_CALL`,`MODE_DISPATCH_ANSWER`,`MODE_CONN_LOST` любое воспроизведение звуков, музыки отключается и вопроизводится соответствующий режиму сигнал. Если в момент отображения специального режима возникают события-сигналы с звуками, не относящиеся к данным режимам - их воспроизведение игнорируется. Например, возможна ситуация, когда в режиме  `MODE_FIRE_ALARM` лифт поедет вниз, появится направление движения и может прийти сигнал на воспроизведение `up.wav` - он должен быть проигнорирован и т.д. Единственное исключение - событие `DING` - воспроизводится всегда, при возникновении (Гонг)
- Сторонние звуки (музыка, направление движения, нажатие кнопки ) можно воспроизводить только при `MODE_NORMAL`
