## Ключевые отличия от v1 (Pi Zero W, 600×1024)

| Параметр | v1 (dev-pi) | v2 (dev-pi2w) |
|---|---|---|
| SoC | BCM2835 (ARMv6) | BCM2710A1 (ARMv8-A, 4× Cortex-A53) |
| Дисплей | 600×1024 | **1080×1920** |
| I2S overlay | `googlevoicehat-soundcard` | **`hifiberry-dac`** |
| Рендер цифр | PNG `chars/N.png` | **Font renderer CalSans260 325pt** |
| Ассеты BACK/MODE | 600×1024 | **1080×1920** |
| Стрелки | 188×209 | **172×191** |
| Грузоподъёмность | 237×59 | **237×59** (без изменений) |
| Нотификации | 600×150 @ y=874 | **1080×270 @ y=1650** |
| DIGIT-слот | 202×346 (PNG) | **450×239 (font renderer)** |
| Видео | `win=0,0,600,800` | **`win=0,0,1080,1920`** |

## Команды мониторинга (держать открытыми во время тестов)

```bash
# Терминал 1 — основной лог indicator
just pi::logs
# или: ssh pi@indicator-95e49a.local 'journalctl -u indicator -f --no-pager'

# Терминал 2 — лог media-ingest
just pi::logs-ingest
# или: ssh pi@indicator-95e49a.local 'journalctl -u media-ingest -f --no-pager'

# Терминал 3 — renderer + UART-фреймы
ssh pi@indicator-95e49a.local \
  'journalctl -u indicator -f | grep -E "renderer:|frame #|dispatch:|audio:|ingest:.*status"'

# Терминал 4 — только аудио
ssh pi@indicator-95e49a.local 'journalctl -u indicator -f | grep "audio:"'
```

> **Примечание по overlayfs.** Испытания проводятся при **активном overlayfs**
> (предусловие П-6). Конфиги в `/data/pi_nku_configs` (ext4, writable) — допускают правки.

Выполнить перед **любым** тестом. Все пункты должны быть ✅.

| П-6 | overlayfs ВКЛЮЧЁН | `just pi::overlay-status` | `overlayfs: ВКЛЮЧЁН (rootfs protected)` | ☐ |

Цель: система корректно стартует, конфиги загружаются, omxplayer открывает окно 1080×1920.

### С-1 — Последовательность строк при старте

| Поле | Значение |

| **Действие** | `just pi::restart`, затем `just pi::logs-tail 40` |
| **Лог (порядок обязателен)** | `indicator starting` |
