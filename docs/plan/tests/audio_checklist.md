| **Лог** | `audio: playing 'up.wav' prio=2` |

## Группа B — Музыкальный lifecycle

Цель: `music_wanted` правильно устанавливается и сбрасывается.

---

### B-1 — UP → музыка запускается автоматически

| Поле | Значение |
|---|---|
| **Предусловие** | `music_volume_percent > 0` в конфиге |
| **Триггер** | `SOUND_UP` |
| **Аудио** | `up.wav` → небольшая пауза (worker loop) → `mus1.wav` начинается |
| **Лог** | `audio: playing 'up.wav' prio=2` / `audio: music 'mus1.wav'` |
| **Критерий** | `mus1.wav` начинается без ручного триггера; `needs_music=1` привело к автозапуску |
| **Результат** | ☐ Pass  ☐ Fail |
| **Примечание** | |

---

### B-2 — Музыка ротируется циклически

| Поле | Значение |
|---|---|
| **Триггер** | Дождаться окончания `mus1.wav` без прерываний |
| **Аудио** | `mus1.wav` → `mus2.wav` → … → `mus7.wav` → `mus1.wav` |
| **Лог** | `audio: music 'mus1.wav'` / `audio: music 'mus2.wav'` |
| **Критерий** | Следующий трек начинается без щелчка; индекс увеличивается циклически |
| **Результат** | ☐ Pass  ☐ Fail |
| **Примечание** | |

---

### B-3 — BUTTON не сбрасывает музыку ⚠️ нетривиальный

| Поле | Значение |
|---|---|
| **Триггер** | Во время воспроизведения музыки — `SOUND_BUTTON` |
| **Аудио** | Музыка обрывается → `button.wav` → музыка возобновляется |
| **Лог** | `audio: music 'musN.wav'` / `audio: playing 'button.wav' prio=2` / `audio: music 'musN.wav'` |
| **Критерий** | `music_wanted` остался `1`; музыка возобновляется после `button.wav`; `prio=2` вытесняет `prio=3`, но флаг не сбрасывает |
| **Результат** | ☐ Pass  ☐ Fail |
| **Примечание** | |

---

### B-4 — DING сбрасывает музыку

| Поле | Значение |
|---|---|
| **Триггер** | Во время музыки — `SOUND_DING` (лифт прибыл) |
| **Аудио** | Музыка обрывается → анонс этажа → тишина (музыка не возобновляется) |
| **Лог** | `audio: preempt by prio=1` / `audio: playing 'N.wav' prio=1` / `audio: playing 'floor.wav' prio=1` |
| **Критерий** | `music_wanted=0` после DING; музыка после анонса **не** возобновляется |
| **Результат** | ☐ Pass  ☐ Fail |
| **Примечание** | |

---

### B-5 — `music_volume_percent=0` → музыка не запускается

| Поле | Значение |
|---|---|
| **Предусловие** | Установить `music_volume_percent=0` в конфиге, перезапустить демон |

## Группа C — Вытеснение по приоритету

Цель: `CRITICAL(0) > FLOOR(1) > MOVEMENT(2) > MUSIC(3)` работает корректно.

---

### C-1 — CRITICAL вытесняет MOVEMENT в середине файла

| Поле | Значение |
|---|---|
| **Триггер** | Во время `SOUND_CLOSING` — отправить `SOUND_FIRE_ALARM` |
| **Аудио** | `closing.wav` обрывается на середине → `fire.wav` немедленно |
| **Лог** | `audio: preempt by prio=0` / `audio: playing 'fire.wav' prio=0` |
| **Критерий** | Задержка от события до начала `fire.wav` < 200 мс; `closing.wav` не доигрывает |
| **Результат** | ☐ Pass  ☐ Fail |
| **Примечание** | |

---

### C-2 — FLOOR вытесняет MUSIC

| Поле | Значение |
|---|---|
| **Триггер** | Во время музыки — `SOUND_DING` |
| **Аудио** | Музыка обрывается → анонс этажа |
| **Лог** | `audio: preempt by prio=1` / `audio: playing 'N.wav' prio=1` |
| **Критерий** | Анонс начинается < 200 мс после события; музыка не продолжается поверх анонса |
| **Результат** | ☐ Pass  ☐ Fail |
| **Примечание** | |

---

### C-3 — MOVEMENT не вытесняет FLOOR

| Поле | Значение |
|---|---|
| **Триггер** | Во время анонса этажа (`SOUND_DING`) — `SOUND_BUTTON` |
| **Аудио** | Анонс этажа доигрывает до конца; `button.wav` не звучит немедленно |
| **Лог** | Строки `preempt` **отсутствуют** во время анонса |
| **Критерий** | `prio=2` не прерывает `prio=1`; `button.wav` либо встаёт в очередь, либо теряется |
| **Результат** | ☐ Pass  ☐ Fail |
| **Примечание** | |

---

### C-4 — Переполнение очереди не роняет демон

| Поле | Значение |
|---|---|
| **Триггер** | Отправить 5+ `SOUND_BUTTON` подряд очень быстро |
| **Аудио** | Воспроизводится не более 3 `button.wav` |
| **Лог** | `audio: queue full, dropping oldest item` |
| **Критерий** | Демон не крашится; `systemctl status indicator` показывает `active (running)` |
| **Результат** | ☐ Pass  ☐ Fail |
| **Примечание** | |

## Группа D — Отмена музыки (режимы и диспетчер)

Цель: `audio_player_cancel_music()` вызывается в нужных ситуациях.

---

### D-1 — Нештатный режим → музыка немедленно отменяется

| Поле | Значение |
|---|---|
| **Триггер** | Во время музыки — MCU отправляет любой режим `1–255` (напр. `MODE_OVERLOAD`) |
| **Аудио** | Музыка немедленно обрывается; нештатный режим отображается на экране |
| **Лог** | `audio: music cancelled (was playing)` |
| **Критерий** | `cancel (was playing)` в логе; музыка не возобновляется пока режим активен; при возврате в `MODE_NORMAL` музыка не стартует автоматически |
| **Результат** | ☐ Pass  ☐ Fail |
| **Примечание** | |

---

### D-2 — Диспетчерская связь → музыка отменяется

| Поле | Значение |
|---|---|
| **Триггер** | `DISPATCH_CALL` или `DISPATCH_ANSWER` от MCU во время музыки |
| **Аудио** | Музыка обрывается; режим звонка/разговора активен на экране |
| **Лог** | `audio: music cancelled (was playing)` |
| **Критерий** | `cancel` в логе; после завершения диспетчерского режима музыка **не** возобновляется автоматически |
| **Результат** | ☐ Pass  ☐ Fail |
| **Примечание** | |

---

### D-3 — Режим сменился пока музыка не играла → `music_wanted` всё равно сбрасывается

| Поле | Значение |
|---|---|
| **Триггер** | `SOUND_UP` → музыка играет → `SOUND_DING` (музыка стоп) → нештатный режим от MCU |
| **Аудио** | Тишина |
| **Лог** | `audio: music cancelled (music_wanted cleared)` |
| **Критерий** | Флаг сброшен превентивно; при последующем `SOUND_UP` в нормальном режиме музыка снова запустится корректно |
| **Результат** | ☐ Pass  ☐ Fail |
| **Примечание** | |
