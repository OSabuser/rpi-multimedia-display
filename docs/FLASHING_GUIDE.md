# Прошивка SD-карты — Лифтовой индикатор v1.0.0

> Инструкция для производства. Требует: SD-карта ≥ 16 GB, ПК с Windows,
> USB-кардридер.

---

## Содержимое папки `RaspberryPi/`

| Файл | Назначение |
|---|---|
| `balenaEtcher-2.1.6.Setup.exe` | Программа для записи образа на SD-карту |
| `indicator-base-v1.0.0.img.gz` | Образ прошивки |
| `wpa_supplicant.conf` | Настройки WiFi (копируется после записи) |

---

## Шаг 1 — Установить balenaEtcher

Если balenaEtcher уже установлен — пропустить этот шаг.

1. Запустить `balenaEtcher-2.1.6.Setup.exe`
2. Следовать инструкциям установщика
3. После установки программа откроется автоматически

---

## Шаг 2 — Записать образ на SD-карту

1. Вставить SD-карту в кардридер, кардридер — в USB-порт ПК
2. В окне balenaEtcher нажать **Flash from file**
3. Выбрать файл `indicator-base-v1.0.0.img.gz`
4. Нажать **Select target** → выбрать SD-карту

   > ⚠️ **Внимание.** Убедитесь что выбрана именно SD-карта, а не диск ПК.
   > Ориентируйтесь по размеру — SD-карта 16 GB.

5. Нажать **Flash!** и дождаться завершения записи и проверки

   > Запись занимает около 10–15 минут.

6. По завершении balenaEtcher покажет **Flash Complete!** и **автоматически
   извлечёт карту**. Окно можно закрыть.

---

## Шаг 3 — Скопировать настройки WiFi

После того как balenaEtcher извлёк карту, Windows перестаёт её видеть.
Нужно вставить карту заново.

1. **Извлечь** SD-карту из кардридера
2. **Вставить** SD-карту обратно
3. Windows откроет несколько уведомлений о новых дисках — **закрыть их все**,
   ничего не форматировать

   > Если Windows предложит «Отформатировать диск» — нажать **Отмена**.

4. В Проводнике появится небольшой диск с именем **`boot`** (≈ 256 MB)
5. Скопировать файл `wpa_supplicant.conf` **в корень** диска `boot`

   ```
   boot:\
   └── wpa_supplicant.conf   ← сюда
   ```

6. Безопасно извлечь диск `boot` через системный трей
   (правый клик → «Извлечь»)

---

## Шаг 4 — Первый запуск

1. Вставить SD-карту в Raspberry Pi
2. Подать питание
3. Дождаться **двух автоматических перезагрузок** — это займёт около 2 минут

   > При первом запуске устройство автоматически настраивает себя:
   > назначает уникальное имя, подключается к WiFi, включает защиту SD-карты.
   > Не отключать питание в это время.

4. После второй загрузки на экране появится меню настройки параметров —
   дождаться его завершения (30 секунд) или настроить вручную

Устройство готово к работе. ✅

---

## Если что-то пошло не так

| Симптом | Действие |
|---|---|
| Диск `boot` не появился после повторной вставки | Извлечь и вставить карту ещё раз |
| Windows предлагает форматировать диск | Нажать **Отмена**, диск `boot` откроется сам |
| `wpa_supplicant.conf` скопировался но WiFi не работает | Проверить правильность SSID и пароля в файле |
| Устройство не загружается | Повторить прошивку с шага 2 |
| balenaEtcher показывает ошибку при записи | Попробовать другую SD-карту |
